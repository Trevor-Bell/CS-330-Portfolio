# CS-330-Portfolio

## Project Overview

This project was completed for **CS-330: Computational Graphics and Visualization** at Southern New Hampshire University.

The final project focused on developing a **3D graphics application using C++ and OpenGL**. The project brought together concepts and techniques learned throughout the course to create an interactive 3D scene based on a provided 2D reference image.

## Project Objectives

The primary objective of the project was to demonstrate an understanding of computational graphics and visualization by creating a functional and visually accurate 3D environment.

The project incorporated:

- 3D modeling using basic geometric primitives
- Object transformations
- Textures and materials
- Lighting and shading
- Camera positioning and movement
- User interaction
- OpenGL rendering
- C++ programming
- Organization and maintainability of graphics code

## Key Features

### 3D Scene

The application creates a 3D scene containing multiple objects positioned and scaled to represent the provided reference design.

### Object Modeling

Objects are constructed using geometric primitives such as:

- Cubes
- Cylinders
- Spheres
- Other basic 3D shapes

Transformations such as **translation, rotation, and scaling** are used to position objects within the scene.

### Textures and Materials

Textures and material properties are applied to objects to improve their visual appearance and make the scene more closely resemble the reference image.

### Lighting

OpenGL lighting is used to add depth and realism to the scene. Lighting techniques help create highlights, shadows, and variations in the appearance of objects.

### Camera Controls

A virtual camera is used to navigate and view the 3D environment. Camera positioning and movement allow the user to explore the completed scene.

### User Interaction

The application provides interactive controls that allow the user to manipulate the camera and interact with the 3D environment.

## What I Learned

This project provided practical experience with the fundamental concepts behind computer graphics and visualization.

Through the development process, I gained experience with:

- Building 3D scenes programmatically
- Working with the OpenGL rendering pipeline
- Applying transformations to 3D objects
- Implementing textures and materials
- Working with lighting and shading
- Creating and controlling a virtual camera
- Designing interactive graphics applications
- Organizing and maintaining a larger C++ project

The project also reinforced the importance of breaking a complex graphics application into smaller, manageable components. Each object, transformation, texture, and lighting element contributes to the final scene and must work together correctly.
